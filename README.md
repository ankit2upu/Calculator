# 🧮 Calculator Web App

A simple and responsive **Calculator Web Application** built using **HTML, CSS, and JavaScript**.
This project performs basic arithmetic operations with a clean and user-friendly interface.

---

## 🚀 Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🧹 Clear (Reset) button
* ⌫ Delete (Backspace) functionality *(optional if added)*
* 📱 Responsive design (works on mobile & desktop)

---

## 🛠️ Technologies Used

* **HTML** – Structure of the calculator
* **CSS** – Styling and layout
* **JavaScript** – Functionality and logic
